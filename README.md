# Professional Data Analyst Exam

#### author: Jędrzej Wydra

![Data Analyst Badge](DA.png)

## Short summary
Performed data preprocessing and exploratory analysis in R using tidyverse to clean, transform, and aggregate sales data, applying statistical summaries and visualization to identify key patterns across time, methods, and locations.

## Technical summary
Built a reproducible R workflow for data cleaning, categorical recoding, and outlier filtering, followed by exploratory analysis with grouped aggregations and visualizations in ggplot2. Applied variance-based summaries and time-series trend comparisons across sales methods, computing aggregated metrics such as mean revenue, total revenue, and customer distribution. Leveraged tidyverse for efficient data wrangling and faceted visualization to reveal temporal and regional sales dynamics.
